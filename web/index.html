Fastnear reads the selected network. The page reads contract settings, note details, and account keys. mempool.space shows Bitcoin activity.

How to check it

Each panel names its source and NEAR block below the result. Account and transaction ids open on the matching NEAR explorer. Bitcoin addresses and txids open on mempool.space.

Cachet holds no admin key. The contract exposes no method that reaches the signer except an owner unseal or fee resign on an attested, unspent note.
